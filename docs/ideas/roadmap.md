Features

- User login
- User registration (or manual user creation)
- Workspaces
- Workspace members
- Accounts
- Transactions
- Automatic debt calculation
- Audit log
- Responsive UI
- SQLite database

No

- CSV import
- Notifications
- Investments
- Planner
- Attachments
- Charts

Success criterion

I can completely replace my current note-taking workflow.
